# 🎨 그래픽스 프로그래밍 비주얼 가이드

벡터부터 텍스처 매핑까지, **그래픽스 프로그래밍의 기초를 그림과 인터랙티브 데모로 하나하나** 설명하는 웹 가이드입니다. 수식만 보면 막막한 개념들을 슬라이더로 만지고 점을 드래그하며 직관으로 이해하는 것을 목표로 합니다.

## ✨ 특징

- **순수 JavaScript + Canvas** — 프레임워크·외부 라이브러리 0개, 그냥 열면 동작
- **모든 개념에 인터랙티브 데모** — 드래그, 슬라이더로 즉시 반응
- **소프트웨어 3D 렌더러 포함** — MVP 변환, Z-buffer, 조명, 텍스처 매핑을 직접 구현해서 보여줌
- **한국어** 설명

## 📚 다루는 내용

### 1. 기초 수학
벡터 · 행렬 · 좌표계와 변환 · 내적/외적 · 삼각함수 · 선형대수와 기하학

### 2. 2D 그래픽스
픽셀과 색상 · 래스터라이제이션 · 이미지 처리 · 알파 블렌딩 · 스프라이트/텍스처

### 3. 3D 그래픽스
Model→World→View→Projection 변환 · 카메라 · 삼각형과 메시 · 깊이 버퍼(Z-buffer) · 조명과 그림자 · 텍스처 매핑

## 🚀 실행 방법

별도 빌드가 필요 없습니다. 저장소를 받은 뒤:

```bash
# 방법 1: 그냥 index.html 을 브라우저로 열기
# 방법 2: 로컬 서버 (권장)
python -m http.server 8000
# 브라우저에서 http://localhost:8000
```

GitHub Pages로도 바로 배포됩니다 (Settings → Pages → main 브랜치).

## 🗂 구조

```
index.html          # 본문(설명 + 데모 캔버스 배치)
css/style.css       # 스타일
js/lib.js           # 공용 헬퍼 (캔버스/벡터/행렬/UI 컨트롤)
js/demos-math.js    # 1. 기초 수학 데모
js/demos-2d.js      # 2. 2D 그래픽스 데모
js/demos-3d.js      # 3. 3D 그래픽스 데모 (소프트웨어 렌더러)
js/main.js          # 내비게이션/스크롤스파이
```
