# CURRICULUM.md — 렌더링 이론 전체 지도

이 문서는 이 프로젝트가 다루려는 **"현존하는 모든 렌더링 이론·원리"의 마스터 체크리스트**다.
빠짐없음(completeness)을 감이 아니라 상태표로 관리하기 위한 것이다.

## 상태 범례
- ✅ 완성 — 원리·개념·구현 3층이 모두 있음
- 🟡 부분 — 일부 계층만 있음(대개 개념 또는 구현만)
- ⬜ 미착수

## 3층 구조 (모든 주제가 세로로 관통한다)
| 층 | 트랙 | 질문 | 산출물 |
|---|---|---|---|
| **원리** | Physics / Theory | *왜 그런가 (빛·물리·수학)* | 다이어그램 + 수식 유도 |
| **개념** | Interactive | *무엇이 일어나나* | 만지는 캔버스 데모 |
| **구현** | C++ / D3D11 / HLSL | *어떻게 코딩하나* | 컴파일되는 코드 |

각 주제 행의 세 체크칸이 곧 원리/개념/구현 계층의 상태다.
