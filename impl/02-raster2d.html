IMPLEMENTATION · CHAPTER 2

2D 그래픽스 — 직접 구현

GPU에게 맡기기 전에, CPU에서 픽셀을 한 개씩 직접 찍어 그래픽스의 밑바닥을 봅니다. 프레임버퍼·래스터화·이미지 필터·알파 블렌딩·스프라이트를 코드 한 줄·성분 하나까지 파고드는 5개 세부 페이지로 나눠 두었습니다. 완성한 버퍼를 화면에 올리는 부분만 D3D11을 씁니다.

세부 페이지

1 / 5

픽셀과 색상 — 프레임버퍼

화면을 픽셀 배열로 보고 색을 직접 채우기. RGBA 바이트 배치와 프레임버퍼 구조.

Color · Framebuffer · setPixel · clear
2 / 5

래스터라이제이션 — 선과 삼각형

브레젠험 선, 무게중심 삼각형 채우기를 픽셀 루프로. 엣지 함수와 감김.

Bresenham · edge function · barycentric fill
3 / 5

이미지 처리 — 컨볼루션 필터

커널 컨볼루션으로 블러·샤픈·엣지 검출. 경계 처리와 정규화.

convolution · kernel · blur · sharpen · edge
4 / 5

알파 블렌딩 — over 합성

"source over" 공식을 성분별로. 프리멀티플라이드 알파와 D3D11 BlendState.

over 합성 · premultiplied · BlendState
5 / 5

스프라이트 · 텍스처 샘플링

UV 좌표로 텍셀 읽기, 최근접·이중선형 샘플링을 직접. 화면 출력은 D3D11로.

UV · nearest · bilinear · 동적 텍스처 blit
