3D 그래픽스 — 직접 구현

이제 GPU에게 일을 맡깁니다. 정점을 버텍스 버퍼·입력 레이아웃으로 올리고, MVP 행렬로 3D를 화면에 투영하고, 카메라·메시·깊이 버퍼·퐁 조명·텍스처까지 실제 Direct3D 11로 구현합니다. 각 주제를 코드 한 줄까지 파고드는 6개 세부 페이지입니다. 창 생성·디바이스/스왑체인 골격은 개발 환경을 참고하세요.

Model → World → View → Projection

Vertex Buffer · Input Layout · cbuffer · MVP

카메라

Index Buffer · 정점 포맷 · OBJ · DrawIndexed

DepthStencilView · LESS · z-fighting

HLSL 블린-퐁, 법선 행렬, cbuffer 정렬(float3 패딩) 함정을 성분별로.
