3D 그래픽스 — 모던 OpenGL로 직접

2장에서 CPU로 픽셀을 찍었다면, 이제 GPU에게 일을 맡깁니다. 정점을 VAO/VBO로 올리고, MVP 행렬로 3D 공간을 화면에 투영하고, 카메라 · 메시 · 깊이 버퍼 · 퐁 조명 · 텍스처까지 실제 OpenGL 3.3 Core Profile로 구현합니다. 창 생성·GLAD 로딩 보일러플레이트는 개발 환경에서 만든 것을 그대로 씁니다. 셰이더 컴파일/링크의 전체 클래스는 4장에서 다루므로, 여기서는 최소 인라인 버전으로 진행합니다.

주의 이 장의 모든 코드는 glBegin/glVertex 같은 레거시 즉시 모드가 아닙니다. Core Profile에서는 즉시 모드가 제거되어 있으므로, 반드시 버퍼 객체(VBO)와 셰이더를 써야 화면에 무언가 나옵니다.

1. Model → World → View → Projection

3D 점 하나가 화면 픽셀이 되기까지 세 번의 좌표계 변환을 거칩니다. 모델 행렬은 물체를 월드에 배치하고, 뷰 행렬은 카메라 기준으로 세계를 옮기고, 투영 행렬은 원근을 만들어 클립 공간으로 보냅니다. 정점 셰이더에서 projection * view * model * position 순서로 곱하는 것이 핵심입니다(GLM은 열 우선이라 오른쪽부터 적용됨).

  1. 큐브 정점 데이터를 배열로 정의한다 (위치만, 36개 = 12삼각형).
  2. VAO/VBO를 생성하고 정점 속성 포인터를 설정한다.
  3. 최소 정점/프래그먼트 셰이더를 컴파일해 프로그램을 만든다.
  4. 매 프레임 model · view · projection을 GLM으로 만들어 glUniformMatrix4fv로 업로드한다.
  5. glDrawArrays로 그린다.

#include <glad/glad.h>
#include <GLFW/glfw3.h>
#include <glm/glm.hpp>
#include <glm/gtc/matrix_transform.hpp>   // translate/rotate/perspective
#include <glm/gtc/type_ptr.hpp>          // value_ptr

// 최소 셰이더 컴파일 헬퍼 (전체 클래스는 4장 참고)
GLuint makeProgram(const char* vsSrc, const char* fsSrc);

int main() {
    // ... GLFW 창 + GLAD 로딩(개발 환경 참고) ...
    GLFWwindow* window = /* 1280x720 창 */ nullptr;

    // 1) VAO/VBO 생성 후 정점 업로드
    GLuint vao, vbo;
    glGenVertexArrays(1, &vao);
    glGenBuffers(1, &vbo);
    glBindVertexArray(vao);
    glBindBuffer(GL_ARRAY_BUFFER, vbo);
    glBufferData(GL_ARRAY_BUFFER, sizeof(kCubeVertices), kCubeVertices, GL_STATIC_DRAW);
    // location 0 = vec3 위치, stride 3*float
    glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 3 * sizeof(float), (void*)0);
    glEnableVertexAttribArray(0);
    glBindVertexArray(0);

    GLuint prog = makeProgram(kVertSrc, kFragSrc);

    // 유니폼 위치는 한 번만 조회해 캐시
    GLint uModel = glGetUniformLocation(prog, "model");
    GLint uView  = glGetUniformLocation(prog, "view");
    GLint uProj  = glGetUniformLocation(prog, "projection");

    glEnable(GL_DEPTH_TEST);  // 큐브가 앞뒤로 겹치므로 필요(§4)

    while (!glfwWindowShouldClose(window)) {
        glfwPollEvents();
        glClearColor(0.06f, 0.07f, 0.10f, 1.0f);
        glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);

        // 2) 매 프레임 세 행렬을 새로 만든다
        float t = (float)glfwGetTime();
        glm::mat4 model = glm::rotate(glm::mat4(1.0f), t, glm::vec3(0.4f, 1.0f, 0.2f));
        // 카메라를 z축 +3만큼 뒤로 = 세계를 -3만큼 당김
        glm::mat4 view  = glm::translate(glm::mat4(1.0f), glm::vec3(0.0f, 0.0f, -3.0f));
        glm::mat4 proj  = glm::perspective(glm::radians(45.0f),
                                           1280.0f / 720.0f, 0.1f, 100.0f);

        glUseProgram(prog);
        // 3) 업로드: count=1, transpose=GL_FALSE(GLM은 이미 열 우선)
        glUniformMatrix4fv(uModel, 1, GL_FALSE, glm::value_ptr(model));
        glUniformMatrix4fv(uView,  1, GL_FALSE, glm::value_ptr(view));
        glUniformMatrix4fv(uProj,  1, GL_FALSE, glm::value_ptr(proj));

        glBindVertexArray(vao);
        glDrawArrays(GL_TRIANGLES, 0, 36);   // 4) 그리기

        glfwSwapBuffers(window);
    }
    // ... 정리 ...
}
함정 glUniformMatrix4fv의 transpose 인자는 반드시 GL_FALSE여야 합니다. GLM과 GLSL 모두 열 우선(column-major)이라 그대로 넘기면 맞습니다. 여기에 GL_TRUE를 넣으면 물체가 뒤집혀 보입니다.
함정 유니폼은 glUseProgram으로 프로그램을 먼저 바인딩한 뒤에만 설정됩니다. 순서가 바뀌면 값이 조용히 무시되어 아무것도 안 보입니다.
TIP glGetUniformLocation은 매 프레임 호출하지 말고 초기화 때 한 번만 조회해 캐시하세요. 이름 문자열 검색이라 프레임마다 부르면 낭비입니다.

2. 카메라

뷰 행렬은 사실 카메라 변환의 역행렬입니다. 카메라를 오른쪽으로 옮기는 것은 곧 세계 전체를 왼쪽으로 옮기는 것과 같죠. GLM의 glm::lookAt(eye, center, up)이 이 역행렬을 대신 계산해 줍니다. 여기서는 위치·전방(front)·yaw/pitch를 들고 WASD 이동과 마우스 시점 회전을 처리하는 원본 Camera 클래스를 만듭니다.

  1. 위치·전방·업 벡터와 yaw/pitch 각도를 멤버로 둔다.
  2. yaw/pitch로부터 전방 벡터를 삼각함수로 재계산한다.
  3. viewMatrix()는 lookAt(pos, pos + front, up)을 반환한다.
  4. 키 입력은 델타 타임을 곱해 프레임률과 무관하게 이동시킨다.
  5. 마우스 콜백에서 커서 이동량으로 yaw/pitch를 갱신하고 pitch를 ±89°로 클램프한다.
src/Camera.h — 원본 카메라 클래스cpp
#pragma once
#include <glm/glm.hpp>
#include <glm/gtc/matrix_transform.hpp>

enum class Move { Forward, Back, Left, Right };

class Camera {
public:
    glm::vec3 position{0.0f, 0.0f, 3.0f};
    glm::vec3 front{0.0f, 0.0f, -1.0f};
    glm::vec3 up{0.0f, 1.0f, 0.0f};
    glm::vec3 worldUp{0.0f, 1.0f, 0.0f};
    float yaw   = -90.0f;   // -Z를 바라보도록 초기화
    float pitch =  0.0f;
    float speed = 3.0f;     // 초당 유닛
    float sens  = 0.1f;     // 마우스 감도

    Camera() { updateVectors(); }

    // 뷰 행렬 = 카메라 변환의 역행렬 (lookAt이 대신 계산)
    glm::mat4 viewMatrix() const {
        return glm::lookAt(position, position + front, up);
    }

    // 델타 타임 기반 이동 → 프레임률과 무관
    void processKey(Move dir, float dt) {
        float v = speed * dt;
        if (dir == Move::Forward) position += front * v;
        if (dir == Move::Back)    position -= front * v;
        // 오른쪽 벡터 = front × up (정규화)
        glm::vec3 right = glm::normalize(glm::cross(front, up));
        if (dir == Move::Left)    position -= right * v;
        if (dir == Move::Right)   position += right * v;
    }

    // 마우스 이동량(픽셀) → yaw/pitch
    void processMouse(float dx, float dy) {
        yaw   += dx * sens;
        pitch += dy * sens;
        if (pitch >  89.0f) pitch =  89.0f;   // 짐벌 뒤집힘 방지
        if (pitch < -89.0f) pitch = -89.0f;
        updateVectors();
    }

private:
    void updateVectors() {
        // 구면 좌표 → 방향 벡터
        glm::vec3 f;
        f.x = cos(glm::radians(yaw)) * cos(glm::radians(pitch));
        f.y = sin(glm::radians(pitch));
        f.z = sin(glm::radians(yaw)) * cos(glm::radians(pitch));
        front = glm::normalize(f);
        // up을 매번 재직교화하면 롤이 안 생긴다
        glm::vec3 right = glm::normalize(glm::cross(front, worldUp));
        up = glm::normalize(glm::cross(right, front));
    }
};

// 마우스가 움직일 때마다 호출된다
void onMouse(GLFWwindow*, double x, double y) {
    if (gFirst) { gLastX = (float)x; gLastY = (float)y; gFirst = false; }
    float dx = (float)x - gLastX;

3. 삼각형과 메시

실제 모델은 정점 배열만이 아니라 인덱스 버퍼(EBO)로 정점을 재사용합니다. 정점 하나에 위치·법선·UV를 함께 담는 Vertex 구조체를 정의하고, VAO/VBO/EBO를 관리하는 Mesh 클래스, 그리고 .obj 파일을 읽는 최소 원본 로더를 만듭니다.

  1. Vertex = 위치(vec3) + 법선(vec3) + UV(vec2).
  2. Mesh가 VAO/VBO/EBO를 생성하고 glVertexAttribPointer로 3개 속성을 설정.
  3. draw()는 glDrawElements로 인덱스 기반 렌더.
  4. OBJ 로더가 v / vt / vn / f 줄을 파싱하고 다각형을 삼각형으로 분할.
src/Mesh.h — Vertex + Meshcpp
#pragma once
#include <glad/glad.h>
#include <glm/glm.hpp>
#include <vector>

struct Vertex {
    glm::vec3 pos;
    glm::vec3 normal;
    glm::vec2 uv;
};

class Mesh {
public:
    Mesh(const std::vector<Vertex>& verts,
         const std::vector<unsigned int>& indices)
        : count_((GLsizei)indices.size())
    {
        glGenVertexArrays(1, &vao_);
        glGenBuffers(1, &vbo_);
        glGenBuffers(1, &ebo_);

        glBindVertexArray(vao_);

        glBindBuffer(GL_ARRAY_BUFFER, vbo_);
        glBufferData(GL_ARRAY_BUFFER,
                     verts.size() * sizeof(Vertex),
                     verts.data(), GL_STATIC_DRAW);

        glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, ebo_);
        glBufferData(GL_ELEMENT_ARRAY_BUFFER,
                     indices.size() * sizeof(unsigned int),
                     indices.data(), GL_STATIC_DRAW);

        // 속성 0: 위치, offsetof로 구조체 내 위치 지정
        glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE,
                              sizeof(Vertex), (void*)offsetof(Vertex, pos));
        glEnableVertexAttribArray(0);
        // 속성 1: 법선
        glVertexAttribPointer(1, 3, GL_FLOAT, GL_FALSE,
                              sizeof(Vertex), (void*)offsetof(Vertex, normal));
        glEnableVertexAttribArray(1);
        // 속성 2: UV
        glVertexAttribPointer(2, 2, GL_FLOAT, GL_FALSE,
                              sizeof(Vertex), (void*)offsetof(Vertex, uv));
        glEnableVertexAttribArray(2);

        glBindVertexArray(0);   // VAO가 EBO 바인딩까지 기억한다
    }

    void draw() const {
        glBindVertexArray(vao_);
        glDrawElements(GL_TRIANGLES, count_, GL_UNSIGNED_INT, 0);
    }

    ~Mesh() {
        glDeleteVertexArrays(1, &vao_);
        glDeleteBuffers(1, &vbo_);
        glDeleteBuffers(1, &ebo_);
    }

private:
    GLuint  vao_ = 0, vbo_ = 0, ebo_ = 0;
    GLsizei count_ = 0;
};
src/ObjLoader.cpp — 최소 OBJ 로더cpp
#include "Mesh.h"
#include <fstream>
#include <sstream>
#include <string>
#include <vector>

// f 줄의 "v/vt/vn" 한 토큰을 파싱. 인덱스는 1-based, 음수 가능.
// vt/vn은 생략될 수 있다("v//vn", "v/vt", "v").
static void parseFaceVert(const std::string& tok,
                          int& vi, int& ti, int& ni) {
    vi = ti = ni = 0;
    std::stringstream ss(tok);
    std::string a, b, c;
    std::getline(ss, a, '/');
    std::getline(ss, b, '/');
    std::getline(ss, c, '/');
    if (!a.empty()) vi = std::stoi(a);
    if (!b.empty()) ti = std::stoi(b);
    if (!c.empty()) ni = std::stoi(c);
}

// 매우 단순한 로더: 중복 정점을 그대로 펼쳐 인덱스를 순차 발급.
bool loadObj(const std::string& path,
             std::vector<Vertex>& outVerts,
             std::vector<unsigned int>& outIndices) {
    std::ifstream file(path);
    if (!file) return false;

    std::vector<glm::vec3> positions;
    std::vector<glm::vec2> uvs;
    std::vector<glm::vec3> normals;

    std::string line;
    while (std::getline(file, line)) {
        std::stringstream ss(line);
        std::string tag;
        ss >> tag;

        if (tag == "v") {
            glm::vec3 p; ss >> p.x >> p.y >> p.z; positions.push_back(p);
        } else if (tag == "vt") {
            glm::vec2 t; ss >> t.x >> t.y; uvs.push_back(t);
        } else if (tag == "vn") {
            glm::vec3 n; ss >> n.x >> n.y >> n.z; normals.push_back(n);
        } else if (tag == "f") {
            // 다각형의 모든 정점 토큰을 모은다
            std::vector<std::string> toks;
            std::string t;
            while (ss >> t) toks.push_back(t);

            // 팬(fan) 삼각화: (0, i, i+1)
            for (size_t i = 1; i + 1 < toks.size(); ++i) {
                const std::string tri[3] = { toks[0], toks[i], toks[i + 1] };
                for (const auto& s : tri) {
                    int vi, ti, ni; parseFaceVert(s, vi, ti, ni);
                    Vertex vx{};
                    // 음수 인덱스는 끝에서부터, 양수는 1-based
                    vx.pos = positions[vi > 0 ? vi - 1 : positions.size() + vi];
                    if (ti != 0)
                        vx.uv = uvs[ti > 0 ? ti - 1 : uvs.size() + ti];
                    if (ni != 0)
                        vx.normal = normals[ni > 0 ? ni - 1 : normals.size() + ni];
                    outIndices.push_back((unsigned int)outVerts.size());
                    outVerts.push_back(vx);
                }
            }
        }
        // 그 외 태그(#, o, g, s, mtllib 등)는 무시
    }
    return true;
}
주의 이 로더는 학습용 최소 버전입니다. 법선이 없는 OBJ라면 삼각형별로 법선을 계산해 채워야 하고, 대형 모델에서는 정점 중복 제거(해시맵 기반)를 넣어야 VBO 크기가 폭발하지 않습니다. 실무에서는 tinyobjloader나 assimp를 씁니다.
함정 OBJ 인덱스는 1부터 시작합니다. 0-based 배열로 접근할 때 -1을 잊으면 정점이 한 칸씩 밀려 메시가 어긋나거나, 첫 정점을 참조하려다 인덱스가 음수가 됩니다.

4. 깊이 버퍼 (Z-Buffer)

3D에서는 가까운 픽셀이 먼 픽셀을 가려야 합니다. 그리는 순서에 의존하지 않고 이를 자동으로 해결하는 것이 깊이 버퍼입니다. 각 픽셀의 깊이를 저장해 두고, 새 프래그먼트가 더 가까울 때만 통과시킵니다.

  1. 컨텍스트 생성 시 깊이 버퍼 비트를 요청한다(GLFW 기본값은 24비트라 보통 자동).
  2. glEnable(GL_DEPTH_TEST)로 깊이 테스트를 켠다.
  3. glDepthFunc(GL_LESS): 더 작은(가까운) 깊이만 통과.
  4. 매 프레임 GL_DEPTH_BUFFER_BIT도 함께 지운다.
src/main.cpp — 깊이 테스트 설정cpp
// (선택) 깊이 비트 명시 요청 — GLFW는 기본 24로 잡아줌
glfwWindowHint(GLFW_DEPTH_BITS, 24);

// GLAD 로드 후 — 딱 한 번
glEnable(GL_DEPTH_TEST);
glDepthFunc(GL_LESS);   // 기본값이지만 명시하면 의도가 분명

while (!glfwWindowShouldClose(window)) {
    // 색 + 깊이 버퍼를 모두 지워야 한다.
    // 깊이를 안 지우면 이전 프레임 깊이가 남아 물체가 사라진다.
    glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);
    // ... 그리기 ...
    glfwSwapBuffers(window);
}
함정 GL_DEPTH_TEST는 켰는데 매 프레임 GL_DEPTH_BUFFER_BIT를 안 지우면, 첫 프레임 이후 화면이 프리징된 것처럼 보이거나 물체가 아예 안 그려집니다. 색과 깊이는 항상 함께 지우세요.
TIP · Z-파이팅 깊이 버퍼는 비선형이라 near 평면 근처의 정밀도가 압도적으로 높고 far 쪽은 낮습니다. near를 0.001처럼 너무 작게 잡으면 먼 물체 두 면이 번쩍이는 z-파이팅이 생깁니다. 해법: (1) near를 최대한 크게(예 0.1~1.0), far를 필요 최소로, (2) 겹치는 표면은 glPolygonOffset(1.0f, 1.0f) + glEnable(GL_POLYGON_OFFSET_FILL)로 살짝 밀기, (3) 정밀도가 더 필요하면 리버스드-Z 기법.

5. 조명과 그림자 (퐁 셰이딩)

가장 고전적인 조명 모델은 퐁(Phong)입니다: ambient(주변) + diffuse(난반사) + specular(정반사)의 합. diffuse는 max(dot(N, L), 0), specular는 반사 벡터(또는 하프웨이 벡터)와 시선의 각도로 계산합니다. 핵심 함정은 법선 변환입니다. 비균등 스케일이 있으면 법선을 그냥 model로 곱하면 안 되고 법선 행렬 transpose(inverse(model))을 써야 합니다.

  1. 정점 셰이더에서 월드 위치와 법선 행렬로 변환한 법선을 프래그먼트로 넘긴다.
  2. 프래그먼트에서 ambient + diffuse + specular를 합산.
  3. C++에서 광원 위치/색, 카메라 위치, 물체 색 유니폼을 설정.
셰이더 — 퐁 라이팅glsl
// ── 정점 셰이더 ──
#version 330 core
layout(location = 0) in vec3 aPos;
layout(location = 1) in vec3 aNormal;

uniform mat4 model;
uniform mat4 view;
uniform mat4 projection;
uniform mat3 normalMatrix;   // = transpose(inverse(mat3(model)))

out vec3 FragPos;   // 월드 공간 위치
out vec3 Normal;    // 월드 공간 법선

void main() {
    vec4 world = model * vec4(aPos, 1.0);
    FragPos = world.xyz;
    Normal  = normalize(normalMatrix * aNormal);
    gl_Position = projection * view * world;
}

// ── 프래그먼트 셰이더 ──
#version 330 core
in vec3 FragPos;
in vec3 Normal;
out vec4 FragColor;

uniform vec3 lightPos;
uniform vec3 lightColor;
uniform vec3 viewPos;      // 카메라 위치
uniform vec3 objectColor;

void main() {
    // 1) ambient — 항상 존재하는 최소 밝기
    vec3 ambient = 0.12 * lightColor;

    // 2) diffuse — 표면과 빛 방향의 각도
    vec3 N = normalize(Normal);
    vec3 L = normalize(lightPos - FragPos);
    float diff = max(dot(N, L), 0.0);
    vec3 diffuse = diff * lightColor;

    // 3) specular — 하프웨이 벡터 방식(블린-퐁)
    vec3 V = normalize(viewPos - FragPos);
    vec3 H = normalize(L + V);
    float spec = pow(max(dot(N, H), 0.0), 64.0);   // 64 = 광택
    vec3 specular = 0.5 * spec * lightColor;

    // (전통 퐁이라면 reflect 사용:)
    // vec3 R = reflect(-L, N);
    // float spec = pow(max(dot(V, R), 0.0), 32.0);

    vec3 result = (ambient + diffuse + specular) * objectColor;
    FragColor = vec4(result, 1.0);
}
src/main.cpp — 조명 유니폼 설정cpp
glUseProgram(prog);

// 법선 행렬: 비균등 스케일에서도 법선을 올바르게 변환
glm::mat3 normalMat = glm::transpose(glm::inverse(glm::mat3(model)));
glUniformMatrix3fv(glGetUniformLocation(prog, "normalMatrix"),
                   1, GL_FALSE, glm::value_ptr(normalMat));

glUniform3f(glGetUniformLocation(prog, "lightPos"),   1.2f, 1.5f, 2.0f);
glUniform3f(glGetUniformLocation(prog, "lightColor"), 1.0f, 1.0f, 1.0f);
glUniform3fv(glGetUniformLocation(prog, "viewPos"),
             1, glm::value_ptr(gCam.position));
glUniform3f(glGetUniformLocation(prog, "objectColor"), 0.85f, 0.55f, 0.25f);

// (유니폼 위치는 실제로는 초기화 때 캐시하세요)
함정 법선을 model로 그냥 곱하면, 물체를 비균등하게 스케일했을 때 법선이 표면에 수직이 아니게 틀어져 조명이 이상해집니다. 반드시 transpose(inverse(model))을 쓰세요. 균등 스케일만 쓴다면 model의 3×3 부분으로 충분하지만, 습관적으로 법선 행렬을 쓰는 게 안전합니다.
주의 여기서 계산하는 것은 직접 조명뿐이고 그림자는 없습니다. 실제 그림자(섀도우 맵)는 깊이 텍스처를 광원 시점에서 렌더하는 별도 패스가 필요합니다 → 6장 섀도우 맵.

6. 텍스처 매핑

메시 표면에 이미지를 입히려면 텍스처 객체를 만들어 GPU에 올리고, 정점의 UV 좌표로 샘플링합니다. 이미지 디코딩은 헤더 온리 라이브러리 stb_image로 처리합니다.

  1. stbi_set_flip_vertically_on_load(true)로 V축을 뒤집는다.
  2. stbi_load로 픽셀을 읽는다(채널 수 확인).
  3. glGenTextures/glBindTexture 후 glTexImage2D로 업로드.
  4. 래핑·필터링을 설정하고 glGenerateMipmap.
  5. 텍스처 유닛에 바인딩하고 sampler2D 유니폼에 유닛 번호를 알려준다.
src/texture.cpp — stb_image 로딩cpp
// .cpp 하나에서만 구현부 포함
#define STB_IMAGE_IMPLEMENTATION
#include "stb_image.h"
#include <glad/glad.h>

GLuint loadTexture(const char* path) {
    // OpenGL의 UV 원점은 좌하단이라 이미지 세로를 뒤집어야 정상 표시
    stbi_set_flip_vertically_on_load(true);

    int w, h, channels;
    unsigned char* data = stbi_load(path, &w, &h, &channels, 0);
    if (!data) { return 0; }   // 로드 실패

    // 채널 수에 맞는 포맷 선택
    GLenum format = GL_RGB;
    if (channels == 1) format = GL_RED;
    else if (channels == 4) format = GL_RGBA;

    GLuint tex;
    glGenTextures(1, &tex);
    glBindTexture(GL_TEXTURE_2D, tex);

    // 픽셀 업로드 (내부 포맷, 크기, 소스 포맷, 타입)
    glTexImage2D(GL_TEXTURE_2D, 0, format, w, h, 0,
                 format, GL_UNSIGNED_BYTE, data);
    glGenerateMipmap(GL_TEXTURE_2D);   // 밉맵 자동 생성

    // 래핑: UV가 [0,1] 밖일 때 반복
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_REPEAT);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_REPEAT);
    // 필터: 축소 시 밉맵 삼선형, 확대 시 이중선형
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR_MIPMAP_LINEAR);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);

    stbi_image_free(data);   // CPU 메모리는 이제 필요 없음
    return tex;
}

함정 이미지가 위아래로 뒤집혀 나온다면 stbi_set_flip_vertically_on_load(true)를 빠뜨린 것입니다. 대부분의 이미지 포맷은 좌상단이 (0,0)이지만 OpenGL 텍스처 좌표의 원점은 좌하단이라, 로드 시 V를 뒤집어야 맞습니다.
함정 glUniform1i(sampler, N)에 넘기는 값은 텍스처 유닛 번호(N)이지 텍스처 ID가 아닙니다. 실수로 텍스처 객체 핸들을 넣으면 검은 화면이 나옵니다.
TIP 밉맵(glGenerateMipmap)은 축소 렌더링의 캐시 효율과 화질을 동시에 올립니다. GL_LINEAR_MIPMAP_LINEAR(삼선형)를 쓰면 멀리 있는 텍스처의 반짝임(에일리어싱)이 크게 줄어듭니다. 밉맵은 7장에서 더 깊이 다룹니다.
