IMPLEMENTATION GUIDE

C++ / OpenGL로 직접 만들기

개념 가이드에서 "무엇이 어떻게 동작하는가"를 봤다면, 여기서는 "그것을 실제로 어떻게 코딩하는가"를 다룹니다. 모든 코드는 복사해 바로 컴파일할 수 있는 수준의 모던 OpenGL 3.3+ Core Profile 예제입니다.

이 가이드가 가정하는 것

  • C++ 기본 문법 (클래스, 포인터, 표준 라이브러리)
  • 개념 가이드의 내용(벡터·행렬·파이프라인·셰이더 등)을 한 번 훑어봤을 것
  • OpenGL 3.3 Core 이상 (컴퓨트 셰이더 등 일부는 4.3+)

개발 환경 (한 번만 세팅)

모든 챕터 예제는 아래 3개 라이브러리를 씁니다. 표준 조합이라 자료도 가장 많습니다.

라이브러리역할대안
GLFW창 생성 · 입력 · OpenGL 컨텍스트SDL2

CMake 프로젝트 골격

CMakeLists.txtcmake
cmake_minimum_required(VERSION 3.16)
project(gfx_impl)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# GLFW: 서브디렉터리 또는 find_package(glfw3)
find_package(glfw3 CONFIG REQUIRED)
find_package(OpenGL REQUIRED)

add_executable(app
    src/main.cpp
    src/glad.c          # GLAD 로더 (생성기에서 받은 파일)
)
target_include_directories(app PRIVATE include)   # glad/, GLFW/, glm/, stb_image.h
target_link_libraries(app PRIVATE glfw OpenGL::GL)
TIP 윈도우에서 가장 쉬운 길은 vcpkg입니다: vcpkg install glfw3 glm 후 -DCMAKE_TOOLCHAIN_FILE=.../vcpkg.cmake. GLAD는 glad.dav1d.de에서 gl 3.3 Core로 생성해 glad.c / glad/glad.h를 프로젝트에 넣습니다.

최소 실행 코드: 창 띄우고 지우기

모든 예제의 출발점입니다. GLFW로 창을 만들고, GLAD로 함수를 로드한 뒤, 렌더 루프를 돕니다.

src/main.cppcpp
#include <glad/glad.h>
#include <GLFW/glfw3.h>
#include <cstdio>

// 창 크기가 바뀌면 뷰포트도 맞춰준다
static void onResize(GLFWwindow*, int w, int h) { glViewport(0, 0, w, h); }

int main() {
    if (!glfwInit()) { std::fprintf(stderr, "GLFW init 실패\n"); return -1; }

    // OpenGL 3.3 Core Profile 요청
    glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
    glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 3);
    glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);
#ifdef __APPLE__
    glfwWindowHint(GLFW_OPENGL_FORWARD_COMPAT, GL_TRUE); // macOS 필수
#endif

    GLFWwindow* window = glfwCreateWindow(1280, 720, "OpenGL", nullptr, nullptr);
    if (!window) { std::fprintf(stderr, "창 생성 실패\n"); glfwTerminate(); return -1; }
    glfwMakeContextCurrent(window);
    glfwSetFramebufferSizeCallback(window, onResize);

    // GLAD: 컨텍스트를 만든 "후에" 로드해야 한다
    if (!gladLoadGLLoader((GLADloadproc)glfwGetProcAddress)) {
        std::fprintf(stderr, "GLAD 로드 실패\n"); return -1;
    }

    glfwSwapInterval(1); // V-Sync

    while (!glfwWindowShouldClose(window)) {
        glfwPollEvents();

        glClearColor(0.06f, 0.07f, 0.10f, 1.0f);
        glClear(GL_COLOR_BUFFER_BIT);

        // ── 여기서 그린다 ──

        glfwSwapBuffers(window);
    }

    glfwTerminate();
    return 0;
}
함정 gladLoadGLLoader는 반드시 glfwMakeContextCurrent 다음에 호출해야 합니다. 순서가 바뀌면 모든 gl* 함수 포인터가 null이라 첫 호출에서 크래시합니다.
